# AI作曲パイプライン 設計仕様書（ローカル実装引き継ぎ用）

## 目的
AI作曲ツール(Suno)で作ったオリジナル楽曲を「作業用BGM」棚としてストリーミング配信する。
Billboard JAPAN Hot 100の構造的特徴（著作権で保護されない要素のみ）を分析し、
そこから作曲スタイル・歌詞を組み立て、簡易マスタリングまで自動化する。

## 重要な注意事項（実装前に必ず確認）
- **Sunoの利用規約は自動化アクセスを禁止**（2026年時点で公式APIなし）。
  ④のプロンプト入力・生成実行・ダウンロードは**手動操作のみ**とし、Chrome自動操作の対象にしない。
- **Billboard JAPANのスクレイピング可否は未確認**。①でChrome自動操作によるチャート巡回取得を行う場合は、
  事前に billboard-japan.com の利用規約ページを確認すること。ユーザーが手動でコピー＆貼り付けする分には
  問題ない想定。
- Matcheringのリファレンス音源は、正当に権利を持つ音源のみを使用する（チャート上位曲の実音源を
  自動取得してリファレンスにしない）。

## パイプライン全体
```
① チャート分析
   - 入力: ユーザーが手動でBillboard JAPAN Hot 100 TOP20のテキストを貼り付け
   - 処理: 曲名・アーティスト名でWeb検索し、BPM/拍子/調性/楽器編成/タイトル型/歌詞主語を分析
   - 出力: 7曲以上に共通する特徴のリスト（実数付き）

② Styleプロンプト生成
   - ①の共通特徴を英語プロンプトに変換（120字以内、固有名詞なし、3案）
   - 各案に「採用/捨てた共通点」を日本語1行で付記

③ 歌詞生成＋自動検証
   - 構成タグ付きで歌詞生成（[Intro][Verse1]...）、尺2分50秒、主語「キミ」
   - かな読み表記を併記して出力（音数検証の精度確保のため）
   - Pythonスクリプトでモーラ数カウント・禁則チェックを自動実行:
     - 1行12モーラ超え検出
     - 拗音3連続検出
     - 「ん」終わり2行連続検出
   - 違反があれば該当行を修正するループ

④ Suno生成【全工程手動】
   - Style欄・歌詞欄への貼り付け、生成、試聴、ダウンロード対象選定、ダウンロード
   - ステム(パート別)ダウンロードも可能な場合は活用
   - ボーカル・アーティスト名はカタログ全体で固定する:
     - アーティスト名: 事前に1つ決めて全リリースで統一(RouteNoteのアーティストプロフィール分裂防止)
     - ボーカル: SunoのPersonas機能(2026年2月〜)で初回の良いテイクをロックし、以降使い回す
       (Voices機能はより厳密に再現できるが、アップロード音声は自分自身の声等、正当な権利があるものに限る)

⑤ ステムバランス調整【自動】
   - Pedalboardでパートごとにゲイン/EQ調整→ミックスダウン（ステムがある場合のみ）

⑥ リファレンス自動選定【自動】
   - librosaで生成曲のBPM・スペクトル重心(明るさ)・RMS(エネルギー感)を抽出
   - 事前に用意した3つのムードバケットから重み付き距離で最適リファレンスを自動選定
     - バケットA 落ち着き系: 〜95BPM、マイナー寄り
     - バケットB 標準系: 95-120BPM、長調寄り
     - バケットC 推進系: 120BPM〜、steady groove
     - 重み: BPM 0.5 / 明るさ 0.3 / エネルギー 0.2
   - リファレンス音源は各バケット1曲、ユーザーが正当な権利を持つ音源から事前に用意

⑦ マスタリング【自動】
   - Matcheringで⑥のリファレンスに合わせて自動マスタリング

⑧ ラウドネス最終調整【自動】
   - FFmpeg(loudnorm)で -14 LUFS / -1 dBTP に調整

⑨ QCチェック【自動】
   - pyloudnormでLUFS/True Peakを測定、目標範囲外なら⑧を再実行

⑩ フォーマット書き出し【自動】
   - FFmpegでRouteNote要求フォーマットに変換: FLAC (44.1kHz/16bit) ※WAV不可

⑪-a アップロード事前準備【手動・要確認】
   - Sunoの有料プラン契約確認(商用利用権がないとAI楽曲disclosureで配信不可の可能性)
   - ジャケット画像を用意: JPG、3000×3000px正方形、25MB未満、RGBカラースペース
   - AI開示情報の準備: 使用したAIプラットフォーム名・リンク(Suno等)

⑪-b 最終確認・アップロード【手動】
   - 人が試聴確認
   - RouteNoteアップロード時にAI関与を開示(2026年1月改定ポリシーで必須)
   - ISRC/UPCはRouteNoteが自動発行するため事前準備不要
```

## 使用ツール（すべて無料・確認済み）
| 用途 | ツール | 備考 |
|---|---|---|
| ラウドネス正規化 | FFmpeg (loudnorm) | CLI、スクリプト化容易 |
| LUFS測定 | pyloudnorm (Python) | QC自動判定に使用 |
| リファレンスマスタリング | Matchering (sergree/matchering) | pip install可、現役メンテ確認済み |
| ステム処理・エフェクト | Pedalboard (spotify/pedalboard) | pip install可、現役メンテ確認済み |
| テンポ/音響特徴解析 | librosa (Python) | リファレンス自動選定に使用 |
| 基本音声処理 | pydub, sox | フェード等の補助処理 |

## RouteNote提出要件（確認済み）
| 項目 | 要件 |
|---|---|
| 音声フォーマット | MP3またはFLAC、320kbps/16bit/44.1kHz（**WAV不可**） |
| ジャケット画像 | JPG、3000×3000px正方形、25MB未満、RGBカラースペース |
| AI楽曲の開示 | 2026年1月改定ポリシーによりアップロード時に必須。商用利用権の保有確認＋使用AIプラットフォームのリンク提出が必要 |
| 商用利用権 | Suno無料プランでは商用利用権が付与されない可能性が高いため、配信するなら有料プラン契約が前提 |
| ISRC/UPC | RouteNoteが自動発行、事前準備不要 |
| Content ID | AI楽曲はYouTube Content ID登録の対象外 |

## 未確定・ローカル実装時に詰める項目
- Billboard JAPANの利用規約確認（①のスクレイピング可否）
- リファレンス音源3曲の実際の選定（ユーザーが正当な権利を持つ音源から）
- ①のWeb検索を20曲分どこまで丁寧に行うか（時間コストとのバランス）
- Sunoの契約プランが商用利用権付きになっているかの確認
- ジャケット画像の用意方法（自作 or AI画像生成 or 発注など、未検討）
