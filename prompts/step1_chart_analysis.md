# ① チャート分析（チャット主導）

> Suno・Billboard JAPAN とも**自動アクセスしない**。チャートのテキストはユーザーが手動で貼り付ける。

## 入力
ユーザーが Billboard JAPAN Hot 100 の **TOP20**（週間）の「順位・曲名・アーティスト名」テキストを貼り付ける。

## 手順（アシスタントが実施）
1. 各曲について、曲名・アーティスト名で Web 検索し、**著作権で保護されない構造的要素のみ**を調べる：
   - BPM（テンポ）
   - 拍子（4/4 など）
   - 調性（major / minor の傾向）
   - 楽器編成（キック、シンセ、ギター、ストリングス、コーラスなど一般的な語で）
   - タイトルの型（語数・言語・記号の使い方）
   - 歌詞の主語・語りかけの向き（一人称／二人称など、方向性の一般論のみ）
2. **7曲以上に共通する特徴**だけを、マッチした曲数と実数付きで抽出する。
3. `templates/features.example.json` の形式で `work/features_<日付>.json` に保存する。

## 出力
- `work/features_<日付>.json`（②の入力になる）

## やらないこと
- メロディ・コード進行の具体的な採譜、歌詞そのものの引用・要約、実音源の保存
- 7曲未満しか一致しない特徴を「共通」として扱うこと
