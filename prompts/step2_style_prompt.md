# ② Style プロンプト生成（チャット主導）

## 入力
`work/features_<日付>.json`（①の出力）

## 手順（アシスタントが実施）
1. 共通特徴を Suno の Style 欄に貼る**英語プロンプト**へ変換する。
   - **120字以内**／**固有名詞なし**（アーティスト名・曲名・レーベル名を書かない）
   - BPM・調性・楽器編成・雰囲気・ボーカルの扱いを簡潔に列挙
   - 「作業用BGM」棚に合うよう、ボーカルは前に出しすぎない指定にする
   - 差別化要素を1つ混ぜる（例：jazzy chord voicings / spoken-word fragment / cinematic texture）
2. **3案**作る。各案に「採用した共通点／捨てた共通点」を**日本語1行**で付記する。
3. `work/style_<日付>.md` に保存する。

## 出力
- `work/style_<日付>.md`（3案 + 各案の付記）

## 備考
- 実際に Style 欄へ貼るのは④（手動）。ここでは案を用意するだけ。
- 固定する「アーティスト名」「Persona ボーカル」は④の運用メモ側で管理する。
