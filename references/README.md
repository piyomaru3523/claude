# リファレンス音源（⑥⑦で使用）

⑥ の自動選定と ⑦ のマスタリングは、ここに置いた音源に**寄せる**形で処理する
（音声そのものはコピーされず、周波数・音量特性の解析結果だけが使われる）。

## ルール
- **正当に権利を持つ音源のみ**を置く：購入済み楽曲、ロイヤリティフリー音源、
  自分の過去のマスター済み楽曲など。
  チャート上位曲の実音源をここに置かない（仕様書の禁止事項）。
- ボーカルが前に出すぎていない、極端に音圧が高すぎ/低すぎない曲を選ぶ。
- 各バケットに **1曲**（wav / flac / mp3）。複数入れると特徴量の平均を取る。

## バケット
| フォルダ | 方向性 | テンポ目安 |
|---|---|---|
| `A_calm/`     | 落ち着き系・メロウ、マイナー寄り | 〜95 BPM |
| `B_standard/` | 標準系・軽やかで邪魔しない、長調寄り | 95〜120 BPM |
| `C_drive/`    | 推進系・steady groove | 120 BPM〜 |

## 音源を置いたら
```
python scripts/analyze_references.py
```
`references/references.json` に特徴量（BPM / スペクトル重心 / RMS）が書き出される。
音源を差し替えたら再実行すること。
